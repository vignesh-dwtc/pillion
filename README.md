# Pillion

Offline pair | Online groups

A phone-to-phone intercom for a motorcycle rider and pillion: each person keeps their own phone in a pocket and wears their own earbuds, and the two phones carry a live, two-way voice link (WebRTC audio) over a direct link. No signal required.

"Pillion" is a working name; the display name and Android application ID live in `config/identity.json`.

- Working on this repo (humans and Claude): read `CLAUDE.md`, then `docs/PLAN.md`.
- Original brief: `docs/BRIEF.md`. Architecture: `docs/ARCHITECTURE.md`. Decisions: `docs/DECISIONS.md`. Test plans: `docs/TESTING.md`.
- Quick start: `npm install`, `npm run check`, `npm run web` (web verification target), `npm run android` (needs an Android device or emulator and the Android SDK).
